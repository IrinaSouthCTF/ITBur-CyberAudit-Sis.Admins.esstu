## Описание проекта

Автоматический аудитор безопасности Linux — консольное Python-приложение, которое выполняет комплексную проверку локальной системы на наличие уязвимостей, аналогичных найденным в Подзадании №1.

Программа анализирует операционную систему и предоставляет структурированный отчет с подробными рекомендациями по устранению каждой обнаруженной проблемы.

## Запуск приложения
Важно! Для полноценной работы требуется запуск с правами root:

sudo python3 ITBur-CyberAudit-Sis.Admins.esstu.py

Почему требуется sudo?
Доступ к информации о сетевых процессах (команда ss -tulpn)

Чтение файлов в директориях /root и /home/*

Проверка прав доступа к системным файлам

Если запустить без sudo, программа предупредит об этом и выполнит только ограниченный набор проверок.

## Функциональные возможности
Приложение выполняет 4 блока проверок в соответствии с заданием:

1. Анализ прав доступа (File Permissions Audit)
Поиск файлов с опасными правами (777, 666) в директориях /etc, /var, /home

Обнаружение конфиденциальных файлов (пароли, ключи), доступных всем пользователям

2. Сетевой аудит (Network Audit)
Сканирование открытых сетевых портов через ss -tulpn

Идентификация сервисов, работающих на этих портах

Выявление опасных/устаревших сервисов (Telnet, FTP, NFS и др.)

3. Аудит установленных пакетов (Package Audit)
Сбор версий ядра Linux и популярных приложений:

nginx, apache2, mysql-server, openssh-server, postgresql, redis

Сравнение с упрощенной базой известных уязвимостей (CVE)

4. Выдача рекомендаций
Для каждой найденной проблемы предоставляется:

Понятное описание угрозы

Конкретная команда для устранения (например: sudo chmod 644 /etc/shadow, sudo apt upgrade openssh-server, sudo ufw deny 23)

Структурированный вывод в консоли

Дополнительные функции
Проверка безопасности SSH-ключей (права доступа к id_rsa, authorized_keys)

Цветное форматирование вывода для удобства чтения

Работа в двух режимах: полный (с sudo) и ограниченный (без sudo)
