## Описание проекта

`auditor.py` - консольное Python-приложение для автоматизированного базового аудита Linux-системы. Программа анализирует систему, выполняет четыре блока проверок и формирует структурированный отчёт:

1. анализ прав доступа к файлам и каталогам;
2. сетевой аудит открытых локальных портов и сервисов;
3. анализ cron-задач;
4. аудит установленных пакетов и их версий.

Для каждой найденной проблемы приложение формирует краткое описание и рекомендацию по устранению. 

---
## Требования к системе

- Linux (рекомендуется Kali Linux, Debian или Ubuntu);
- Python 3.9 или выше;
- наличие системной утилиты `ss` или `netstat`;
- для полного аудита желательно запускать программу с `sudo`.
---
## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/IrinaSouthCTF/ITBur-CyberAudit-Sis.Admins.esstu.git
cd ITBur-CyberAudit-Sis.Admins.esstu
```

### 2. Проверка версии Python

```bash
python --version
```

### 3. Запуск программы

Базовый запуск:

```bash
python auditor.py
```

Запуск с собственным именем отчёта:

```bash
python auditor.py -o audit_result
```

Рекомендуемый запуск для полного охвата системы:

```bash
sudo python auditor.py -o audit_result
```

Почему может понадобиться `sudo`:

- часть каталогов `/etc`, `/var`, `/home` может быть недоступна обычному пользователю;
- без повышенных прав часть сведений о процессах и сокетах может быть скрыта;
- не все cron-файлы доступны для чтения без прав суперпользователя.
